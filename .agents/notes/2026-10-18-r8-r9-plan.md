## IR deltas (keep old IR byte-identical: only add keys when used)
- try: + "orelse":[stmts], + "finalbody":[stmts], + "brk"/"cont" flag names (only when orelse && flags exist)
- handler: + "bind":str, + "bare":true, + "excslot":str (only when bind or bare-raise inside)
- raise: + "reraise":true + "excslot":name (bare raise), + "cause": {kind:"excmake",exc,code?,message} | {kind:"name",id,type exc} | null

## Runtime ps_rt.c/.h
- ps_exc_current() -> PsExc* ; ps_exc_make(code,n,data) -> PsExc* (no raise)
- ps_exc_set_cause(e,cause) ; ps_raise_exc(e) noreturn ; ps_exc_str(e)->PsBuf(msg|empty) ; ps_exc_args(e)->PsSeq*[16B elems, [msg] or empty]
- ps_deliver uncaught: print cause first + "The above exception was the direct cause of the following exception." then exc.

## Lowering (_stmt.py, __init__.py, builtins.py, _classes.py)
- Lowerer attr `self.exc_stack: list[str] = []` ("" sentinel = unallocated; _temp("exc") lazily on first bare raise inside handler)
- _raise: bare raise ok iff exc_stack nonempty -> reraise node w/ excslot; cause: None|exc local Name|builtin/user-exc Name/Call -> "excmake"; args: ONE scalar arg -> str(arg) msg (bool via str() builtin); >1 args -> PS2003 fence (repr(tuple) not in subset, R8 "if cheap"); non-scalar fences. exc+cause arg-eval share ONE `for which in range(2)` pass inside _raise so no new annotated def joins the self-census.
- _try: handler NAMES resolve before body lowering (keeps old 1-fence abort for unlowered except types, e.g. telemetry.py's OSError); bind -> locals[bind]={"kind":"exc"} (pre-existing non-exc local -> PS1205, keeping the except-as family reachable); dead_names set + _expr._name checks it (CPython `del e` at handler end); bare -> {"bare":true}; exc_stack push/pop per handler -> "excslot" when allocated; orelse/finalbody bodies; brk/cont fields when orelse.
- _lookup_attr: exc.kind + "args" -> ps_exc_args list[str]; builtin_spec: str accepts "exc".

## Deviations from the design doc
- else/break-continue: flags captured on the try node (brk/cont names) instead of doc's flow codes 2/3 — the loop already owns flag mechanics, flow stays 0/1.
- raise-from stores a real PsExc cause link (ps_exc_set_cause); uncaught report prints cause first + CPython's direct-cause line. __cause__ attribute itself is not exposed (PS2001) — documented minimal choice.
- finally: emitted inline in emit_try (no new emitter defs — census-zero discipline).
