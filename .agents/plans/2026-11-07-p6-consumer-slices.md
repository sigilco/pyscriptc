# P6 consumer slices: the remaining raw dict-IR reads, file-disjoint, one free-model agent per 45-minute slice

Date: 2026-11-07. Epic: #817 (drop package P6). Milestone: v0.9.0. Planning only; no code in this PR. Measured on origin/master `4bc0f275` (54 commits past the 2026-11-06 deletion-map snapshot `1c0b88be`, so every count below is fresh, not copied).

P6 converts the compiler's own consumers off raw dict-IR key reads so the v0.10.0 drop PR can delete the dict schema without breaking them. The method is the same as the sibling notes: count literal `obj["key"]` and `obj.get("key")` sites over `src/pyscriptc` for the IR key vocabulary, rank, cut file-disjoint slices. Two measurements matter. The first is the P6 inventory itself (`uv run python scripts/dict_ir_consumers.py`, the five handoff keys `kind/functions/classes/body/span` over the 15 consumer modules): every one of the 15 modules is already at zero raw reads on master, and all 13 forbid-tests pass (`tests/test_p6_ir_seam.py`, `test_dict_ir_consumers.py`, `test_assess.py`, `test_case_reducer.py`, `test_coverage.py`, `test_debug.py`, `test_debug_info.py`, `test_emitter_package.py`, `test_ir_validate_seam.py`, `test_irverify.py`, `test_package.py`, `test_project_mode.py`, `test_restlower_typed_nodes.py`). The named P6 wave (PRs #985, #989, #942, #947 to #951, #1081, #1086, #1089, #1093, #1094, #1096) is done. The second measurement widens the key set to the union of every key the forbid-tests actually guard (the restlower set adds `type/value/target/id/op/left/right/name/object/index/callee/args/elems`; the emitter set adds `expr/cond/then/else/handlers/symbol/island*/fmt/...`; the module-level set adds `functions/classes/sourceFile/entry/fallback/fences/imports/globals`). That union is what still carries signal: 3,403 raw reads remain tree-wide (2,896 subscript loads plus 507 `.get` calls, 729 hand-built `{"kind":` records on top), distributed lower/ 1,505, root modules 1,145, restlower/ 591, emit/ 116, cli/ 46.

Read these numbers as two different jobs wearing one count. Node-dispatch reads (`expr["kind"]`, `arg["type"]["kind"]`, `stmt["body"]`) dominate `lower/` and `restlower/`; they convert locally to existing accessors (`_node_kind`, `_node_type_kind`, `_node_body` in `lower/_core.py` and `restlower/_shared.py`). Module-surface reads (`module["functions"]`, `module["fences"]`, `module["sourceFile"]`) dominate the root consumers; they need a small module-level accessor group added to `emit/_ir.py`, which is the only file all slices touch, so the slices are staged in waves that add accessors first, then convert against them (parallel-pr-rules: one open PR appending to `emit/_ir.py` at a time; accessor waves go first because every later slice imports them).

## Slice format

Each slice: one agent, one branch, 45 minutes, conventional commit, `Closes #N` if it closes an issue else `Refs #817`. Files are disjoint across concurrently open slices. Every slice names the accessor it adds or uses, the forbid-test that guards it, and the hotspot to avoid (a file another wave or lane owns). Census repin (`uv run python scripts/repin_census.py`) touches only the shards of the files the slice edited; generated artifacts are never hand-merged.

## Gaps

Counts are AST-site counts over origin/master `4bc0f275` and drift as slices land; re-measure before assigning each wave. The guarded key union is conservative: some counted sites are the tool's own report dicts (`assess.py`'s `imports`, `coverage.py`'s `fences` summaries, `imports.py`'s report), and each slice body notes which reads stay deliberately; the honest per-slice target is "no raw read of a lowered-module record", not the raw number. The union also counts dict-literal *writes* to `{"kind":` shapes that are the module's own output rather than an IR read (729 across the tree); those are the `dict_build` column and each slice converts them only where the record is an IR node. The restlower pilot test counts subscript loads but not `.get` calls, so R8's widening will surface sites the pilot's numbers hide (the six `_argparse.py` reads are already known). `coro.py` (138 raw, 131 builds) is named in no slice: it converts with R-2 (the typed coroutine port), not in P6, per the deletion map's step 2.
