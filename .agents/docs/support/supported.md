# What is supported

This document describes the supported surface of builtins and standard-library modules in pyscriptc.
Live per-construct status and counts are published nightly on the [compat site]({{PYSC_COMPAT_URL}}) and in the public data file `compat/data/support.json`.

## Status vocabulary

- 🟢 **Fully supported**: every probed form compiles cleanly to native IR.
- 🟡 **Partial**: lowered subset handles common typed forms; unlowered methods or call shapes stop at a fence or route to the island floor.
- 🔴 **Not supported**: unadmitted import or construct not yet lowered natively.

## Refusals and fences

A **fence** is a coded refusal: when a construct is outside the supported subset, compilation stops with a `PSxxxx` diagnostic code (`pyscriptc explain PSxxxx`).
Fence codes are defined per construct rather than per module:

- `PS1xxx`: annotations, types, and inference requirements (`PS1001` unannotated variable, `PS1003` unlowered type shape).
- `PS2001`: name missing from an otherwise lowered module (for example `math.asin`).
- `PS2002`: unlowered language construct or module import outside the closed table.
- `PS2003`: unlowered call arguments (unsupported keyword arguments or arity mismatches).
- `PS2004`: unsupported operator combinations.
- `PS42xx`: structural refusals by design (for example dynamic attribute protocol hooks `__setattr__` or `__getattribute__`).

## Data sources

The supported surface is evaluated through compile probes (`pyscriptc.lower.lower_file`) defined in `scripts/support_data.toml` against the closed import table in `pyscriptc.stdlib_queue`.
Measurements are generated by `scripts/gen_support_table.py` into `compat/data/support.json`.

Deliberate differences from standard CPython 3.14 are cataloged in [Divergences from CPython](../../../docs/reference/divergences.md).
Live status across all modules lives on the [compat site]({{PYSC_COMPAT_URL}}).
