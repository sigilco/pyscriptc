# Roadmap

The stdlib queue is finished. Higher compatibility with the top 100 is a language problem, and then a packaging problem. It is not another wave of `math` and `json`.

## Words

A **gate** is a slice that already lowers. `gates-v1` is three of them: the closed import table, containers (`list`, `dict`, string methods, `for`, exceptions), and annotated classes.

A **fence** is the `Fence` diagnostic (`PS2xxx`, exit 3) that refuses everything else and emits no binary.

The benchmark ratio check (time 2×, RSS 1.25×) is unrelated. Do not call that a gate.

## Where things stand

`certifi` is the one hugovk top-100 library that counts: `certifi.core.where()` matches CPython, and `__main__.py` is not part of the importable library. The scorer compiles pinned sdists under `benchmarks/compat/top100/` and counts a library only when one of its own functions is called and matches CPython. Native wheels stay native-only. A project with no pinned tree is unattempted, not a hardcoded import-table fence. `tzdata` compiles and has no function, so it does not count. What does lower is one annotated file, a directory of files whose relative imports name a function, a module-level constant, or a class the defining module emits, and the S wave plus the M wave: keywords and stored constant defaults, same-type `and`/`or`, truthiness of `str` / `bytes` / `int` / `list` / `dict`, `split` / `join` / `encode()` / `decode()`, Latin-1 literals, step-1 slices, `str` of `int` and `float`, plain f-strings and `%s` / `%d`, list comprehensions with one `for`, `with open(...) as f`, and tuples of two or more fields (tuple equality stays a fence; `re.findall` still stops at four groups). A literal `re.findall` with two to four groups returns a tuple of strings. `import typing`, `import typing_extensions`, and a type-related `from __future__ import` are erased. A call such as `typing.cast` stays a fence. Module-level constants lower. `string` constants, `bisect_left` / `bisect_right` on `list[int]`, and a closed set of `errno` constants lower. Strings are indexed one byte at a time (`ps_str_get`). `importlib` and `asyncio` import and then fence.

`lower.py` still typechecks, desugars, and emits in one class. Keywords and defaults go through `_fill_args`. `fail` collects every fence in a function or class body. The desugar pass, the single intrinsic table, and `match` on `ast.stmt` / `ast.expr` are still open. Do not describe that split as done.

About a fifth of the top 100 is a native or Rust core (cryptography, cffi, pydantic-core, numpy, pandas, pillow, pyarrow, scipy, grpcio, protobuf, greenlet, rpds-py, charset-normalizer, yarl, multidict, frozenlist, propcache). Those stay on CPython. The reachable band is the small pure-Python packages: certifi, mdurl, trove-classifiers, tzdata, iniconfig, python-dotenv, shellingham, platformdirs, pathspec, pytz, colorama, pyjwt, jmespath, filelock, zipp, h11, packaging, idna. requests, urllib3, boto3, pydantic, and click are the tier after that.

## Order to implement

Desugar into the core the IR already has (calls, `if`, `while`, assign, `try`, list, dict, class). Do not add an IR kind per feature.

**S, any order, keywords first.** `split` / `join` / `encode()` / `decode()` with no extra arguments. Truthiness of `str`, `bytes`, `int`, `list`, `dict`. `and` / `or` when both sides have the same type. Keywords reordered into the positional call, and defaults actually stored. Latin-1 literals (code points 0–255), so indexing stays one byte per code point.

**M.** Slices with a step of 1 (`s[1:]`, `s[:-1]`). `int` / `float` to `str`, then f-strings and `%s` / `%d` with no format spec. List comprehensions via the existing `for`-to-`while` plus list growth. `with open(...) as f` and `close` on each exit, the same special case as `contextlib.suppress`. Tuples of two or more typed fields on the same synthetic class. `re.findall` still returns a tuple only for two to four groups.

**L.** Done for the names below. Directory compile and relative imports of functions and constants were already in. `super()`, multiple inheritance, user decorators, `field(default_factory=...)`, keyword-only and positional-only parameters, `**kwargs`, and starred calls stay fences.
- Single inheritance. Layout is the parent's fields, then the class's own. Method lookup walks the parent. A user subclass of `Exception` (or another lowered exception) is one more exception code, raised and caught as its own type and as the parent. `raise` does not call `__init__`. An inherited field the subclass never assigns reads as `0`.
- `@property` (getter only), `@staticmethod`, and `@classmethod`. `Class.method(...)` does not pass the class object. A body that reads `cls` is an unbound name.
- A flat `@dataclass` that only generates `__init__` from annotations, including a constant default. No base and no written `__init__`.
- `enum.IntEnum` and `enum.Enum` members are integer constants. `Enum` equality of two members matches CPython. Equality to the raw int, and arithmetic, match `IntEnum` rather than `Enum`.
- `*args` of one element type, lowered as a `list` of that type.
- `set` of `int` or `str`: display, `set(list)`, `add`, membership, `len`, and iteration. Iteration is insertion order. No new IR kind. Subscript stays a fence.

**L, not XL, for the C-shaped subsets.** A `finally` whose body does not itself `return` or `raise`. A printf-shaped format list (`%s` `%d` `%f` `%x` and a width). `argparse` as a fixed table of flags into an annotated result. These map onto a cleanup edge, `snprintf`, and `getopt_long`.

**XL is only the part that is not that C concept.** `__exit__` that can swallow an exception. Format fill, align, dynamic width, and `__format__`. `argparse` `type=` and `action=`. `importlib.resources` once packages exist. Upstream `h11`.

**XXL, leave fenced.** Lambdas, user decorators, `functools.partial`, `wraps`, `lru_cache`. `**kwargs`. A mixed `and` / `or` used as a value. `abc`, multiple inheritance, `super()`, metaclasses. `http.client`. Upstream `requests` and `httpx`.

## HTTP, separately

A script that fetches a URL is not `import requests`. An island call, `ps_island_http_get(url) -> bytes` plus POST and a status code, is **M** and matches `subprocess.check_output`: embedded CPython does the work, the binary links libpython, speedup stays near 1×. HTTP/1.1 in the C runtime with no TLS is **L**. The same closed signature over HTTPS (libssl, SNI, CA bundle) is **XL**, and it is how you keep the small non-island binary. Return `bytes` and let the caller `decode()`, so `charset-normalizer` never enters. `httpx` is harder than `requests` because of `anyio`. Cookies, pools, streaming, and multipart stay on CPython.

## How to change the compiler before grinding features

`lower.py` typechecks, desugars, and emits in one class. `_module_call` is a chain of special cases, while `STR_METHODS`, `WAVE_FUNCTIONS`, and `REST_FIXED` are three tables doing one job. `fail` raises, so the first fence hides the rest.

1. A desugar pass in front of the lowerer. Syntax becomes core IR. LLVM learns nothing new.
2. One intrinsic table: name, argument types, default, C symbol. Keywords and arity are checked once. Keep a hand-written lowerer only for `json.loads`, literal `struct` formats, and `re.findall`.
3. `match` on `ast.stmt` and `ast.expr` for that desugar pass, with the wildcard arm as the fence. `lower_expr(node, env) -> Expr`. Do not put two hundred stdlib functions in a `match`.
4. IR nodes as a sum of dataclasses, still serialized to the current JSON, so a missed LLVM case fails the typecheck.

## What 80% and 10 of 100 actually are

CPython 3.14 has 164 top-level stdlib modules. The queue imports about 30 of them, and inside those modules on the order of a tenth of the public names lower (`os` is 7 names out of about 200). Eighty percent of all 164 modules is a different project from the top 100, and it runs through tkinter, idlelib, and the rest of `os`. Do not schedule that.

The denominator that moves adoption:

- **Stdlib, 80–90%.** Of the stdlib modules the 18 pure-Python packages actually import, the frequent ones are already in the queue (`sys`, `os`, `re`, `collections`, `functools`, `pathlib`, `contextlib`, `itertools`, `warnings`, `stat`, `ctypes`). The files still die first on language fences and on two imports we refuse outright: `typing` (11 of 18) and `__future__` (8 of 18). Closing that gap is erasure plus a short list of missing modules, not more of `os`.
- **Top 100, 10–20 libraries.** The October 2026 band is certifi, mdurl, trove-classifiers, tzdata, iniconfig, python-dotenv, shellingham, platformdirs, pathspec, pytz, colorama, pyjwt, jmespath, filelock, zipp, h11, packaging, idna. Native wheels stay on CPython. A 1.5× end-to-end gain counts. The native probe already cleared that when the compiled loop called a C ABI once (28×) or on every iteration (about 4×), and when one island call sat beside the loop (2.2×). An island call on every iteration was 0.8×. One-shot island calls are in budget. Per-element island calls are not.

## Next tasks

1. **Desugar pass and one intrinsic table.** Still open. `fail` already collects fences inside a function or class body. Keywords and defaults already go through one filler. The structural split (a desugar pass, one intrinsic table, `match` on `ast.stmt` / `ast.expr`, IR nodes as dataclasses) has not been done.
2. **Erase `from __future__ import annotations` and annotation-only `typing` / `typing_extensions` imports.** Done. A call such as `typing.cast` or `get_type_hints` stays a fence.
3. **S.** Done. Keywords, stored defaults, same-type `and`/`or`, truthiness, `split` / `join` / `encode()` / `decode()`, Latin-1 literals.
4. **M.** Done, including tuples of two or more fields and literal `re.findall` of two to four groups. Five or more groups stays a fence. Tuple equality stays a fence. A dynamic pattern with two or more groups raises `ValueError`.
5. **Module-level constants and a directory compile.** Done for functions, module-level constants, and classes the defining module emits. `pyscriptc compile DIR --call pkg.mod.func` resolves `from .mod import name` and `from ..mod import name`. A class defined in two modules under different shapes is a fence. Identical synthetic classes are skipped. A class that does not lower is still not exported.
6. **Closed stdlib surfaces the band imports and we do not have.** Done for the names below. `string`, `bisect`, and a closed set of `errno` constants were already in.
   - `importlib.resources.files` / `as_file`. One direct lookup of a directory on the compiler's `sys.path`. No zip. `read_text` stays Latin-1 even when the encoding keyword is `ascii` or `utf-8`.
   - `hmac.digest`, `hmac.new(...).digest()`, and `hmac.compare_digest` for a literal `md5` / `sha1` / `sha256` / `sha384` / `sha512`. The hash is in the small runtime, not an island call per token.
   - `unicodedata` as a direct Latin-1 table (`category`, `combining`, `normalize`, `is_normalized`, and the other closed names). A form that would leave Latin-1 raises `ValueError`. `ucd_3_2_0` and the rest of the database stay out. This is not full `unicodedata`.
   - `tempfile.gettempdir`, `gettempprefix`, `mkdtemp`. `atexit.register` of a no-argument function. `shutil.copyfile` and `shutil.rmtree`. `NamedTemporaryFile`, `which`, and `unregister` stay fences.
7. **L, which is the second 10.** Done for single inheritance (including a user exception subclass), `@property` / `@staticmethod` / `@classmethod`, a flat `@dataclass`, integer `enum`, `*args` of one type, and `set` of `int` or `str`. `collections.abc` used as a base, full `abc`, `super()`, and metaclasses stay open. User decorators, `functools.partial`, `**kwargs`, and starred calls stay fenced.
8. **Pinned top-100 compiles, `bool()`, and `list()`.** Done as a measurement, not as a counted library. The band is vendored with versions and hashes. `bool()` covers the types whose truthiness already lowers, including `nan`. `list()` copies a `list`, a `set`, or `*args`. `typing.Set` unwraps like `typing.List`. A directory compile also resolves an absolute import of that same package for a function or a constant. `tzdata` is partial. No package function was called in that snapshot.
9. **Class export, version checks, longer tuples, and real builtin calls.** Done inside the IR that already exists. A directory compile exports a class the defining module emits, including an exception class and its code. `if sys.version_info` compared with a tuple of ints keeps the taken branch. `global` of a module `None` slot holds a `str`, an `int`, or a `Path`. `as_file(...).__enter__` is that path and `__exit__` is a no-op, so `certifi.core.where` matches CPython from one lookup and does not link libpython. Tuples past four fields use the same `tuple_N_…` class. `all`, `any`, `enumerate`, and `zip` are real calls; `enumerate` and `zip` are only `for` iterators. `mdurl`'s nine-string `__all__` is past the tuple cap.
10. **`__main__.py` is not the library, and a missed export names the definition fence.** Done. A directory compile skips only `__main__.py` and says so. `certifi.core.where([])` matches CPython, so certifi counts. An `argparse` import in any other module stays a fence. A subclass of a class exported by another module in the tree is exported. `IDNABidiError`, `Options`, `Connection`, `PyJWK`, `PlatformDirsABC`, `GitIgnoreSpec`, `AcquireReturnProxy`, `encode`, `dotenv_values`, `init`, and `ShellDetectionFailure` still do not export: the first fence is inside the definition (`ABC` / `Generic` / another class that did not lower, `Optional`, a keyword-only parameter, a missing annotation, or a decorator). Those packages stay fenced. The first remaining fence of each compile is in `.agents/docs/support/supported.md`.
11. **`class C(object)` is a class with no base.** Done. `class C(object)` and `class C(object,)` emit the same class as `class C`. `object.__init__` is not emitted. Multiple bases stay a fence. `jmespath.visitor.Options` still does not lower: `parameter dict_cls needs an annotation`. jmespath does not count. `abc`, `Generic`, `Optional`, and keyword-only parameters stay fenced.
12. **`dict.keys()` is the key list.** Done. CPython returns keys in insertion order, and that result is the `list` the IR already builds. A constant dict folds to the list; a runtime dict copies keys. trove-classifiers compiles and stays partial: `sorted_classifiers`, `classifiers`, `deprecated_classifiers`, and `all_classifiers` are constants, and there is no function to call. `dict.values()` and `dict.items()` stay fenced.
13. **Leave fenced while the list above is open.** The rest of `os`, `inspect`, `asyncio`, and `socket`. `http.client`, user decorators, `functools.partial`, and upstream requests. An HTTP island is worth adding when a script does real Python around one fetch. The fetch alone ties CPython, which is the `.so`-heavy row of the native probe. The desugar pass, one intrinsic table, `match` on `ast.stmt` / `ast.expr`, and IR nodes as dataclasses stay open.

## Suggested build order

S and M are in, including tuples of two or more fields, and so are module-level constants and the directory front end. Task 6's closed names are in (`importlib.resources.files` / `as_file`, `hmac` for one call per token, Latin-1 `unicodedata`, `tempfile.gettempdir` / `gettempprefix` / `mkdtemp`, `atexit.register`, `shutil.copyfile` / `rmtree`). Task 7's L names are in (single inheritance, the three method decorators, a flat `@dataclass`, integer `enum`, `*args` of one type, and `set` of `int` or `str`). Task 8 compiles the pinned band for real: `bool()` and `list()` lower. Task 9 exports classes, folds `if sys.version_info`, lowers `global` and `as_file(...).__enter__`, lifts the tuple cap, and scores `all` / `any` / `enumerate` / `zip` as real calls. Task 10 skips `__main__.py`, so `certifi.core.where` counts, and a class or function that does not lower reports the fence inside the definition. Task 11 lowers `class C(object)` as a class with no base. Task 12 lowers `dict.keys()` to the key list in insertion order. trove-classifiers stays partial. A module f-string of `str` constants, such as packaging's `f"2014 {__author__}"`, is that one `str` constant. `IO[bytes]` and `BinaryIO` are the `BytesIO` handle `open` already returns; `IO[str]` and `TextIO` are the `TextIO` handle. `tuple[int, ...]` of one lowered element is that `list`. The value is a list: length, index, and the sum match CPython, and the repr and the type name do not. A module `if TYPE_CHECKING:` is omitted, the same way a false `if sys.version_info` branch is. A module set of `str` or `int` constants, such as packaging's `_ALLOWED_ARCHS`, is that set list, copied at each use. Iteration is insertion order, not CPython's hash order. `x is None` and `x is not None`, either side, are `==` and `!=` against `None` for a type that can compare. `a if cond else b` is that `if`, and only the taken operand runs. `frozenset` of a list or set display of `str` or `int` constants, such as packaging's `_REQUIRED_ATTRS`, is that set list. Iteration stays insertion order, and `.add` / `.remove` stay fenced on a name bound to it. `frozenset` of one `str` constant, such as packaging's `_SIMPLE_VERSION_INDICATORS`, is the set of those characters. A module `re.compile` of one `str` constant, such as packaging's `_NORMALIZE_PATTERN`, is that `Pattern`, inlined at each use. Membership in a tuple of `str` or `int` constants, such as packaging's `env_var in ("platform_python_implementation", "python_implementation")`, is `==` joined by `or`. `float("inf")`, such as packaging's `_BOUNDARY_INF`, is the float const `math.inf` already uses, and `float("-inf")` is that const negated. A float `in` a list is `==`, so NaN is not a member. A chained comparison is those compares joined by `and`: the middle value is stored once, and a false link does not evaluate the rest. A list comprehension with one filter is that `if` around the list push, and a false filter does not evaluate the element. `break` leaves the nearest loop, and `continue` skips the rest of that body and returns to the test. `assert` is `if not` plus the existing `Exception` raise. `**` of two ints is a loop of `*`, and a negative exponent stays fenced. A slice step keeps every step-th element, and a negative step stays fenced. `match` of a literal is `if` plus `==`, and other patterns stay fenced. `del` of one unread local is dropped, and `del` of an attribute, a subscript, a slice, a tuple of names, or a name that is read later stays fenced. A module `@staticmethod` is the function a class `@staticmethod` already emits, and other module decorators stay fenced. A mixed `or` in a condition is truthiness joined by bool `or`, and a mixed `or` used as a value stays fenced. `functools.reduce(operator.add, xs)` of a non-empty `list[int]` is a loop of `+`, and an initializer on that call stays fenced. `collections.OrderedDict()` with no arguments is an empty dict, and a positional iterable, keyword arguments, `move_to_end`, `popitem`, and equality with a dict stay fenced. `re.A` and `re.ASCII` are the int constant 256, and the other `re` flags stay fenced. `warnings.defaultaction` is the str constant `"default"`, and `warn`, `filters`, and `simplefilter` stay fenced. `inspect.AGEN_CLOSED` is the str constant `"AGEN_CLOSED"`, and `signature`, `getsource`, and `stack` stay fenced. `threading.TIMEOUT_MAX` is the float const `9223372036.0`, and `Thread`, `Lock`, and `Event` stay fenced. `logging.BASIC_FORMAT` is the str constant `"%(levelname)s:%(name)s:%(message)s"`, and `basicConfig`, `getLogger`, and handlers stay fenced. `asyncio.ALL_COMPLETED` is the str constant `"ALL_COMPLETED"`, and `run`, `gather`, and `sleep` stay fenced. `subprocess.DEVNULL` is the int constant `-3`, and `run`, `Popen`, `PIPE`, `STDOUT`, and `call` stay fenced. `re.DEBUG` is the int constant 128, and `re.I`, `re.M`, `re.S`, `re.X`, `re.L`, and `re.U` stay fenced. `re.DOTALL` is the int constant 16. Int constants whose harness probe is `return module.NAME` on an already-lowered module are that CPython int, including the remaining `re` flags. Latin-1 str constants on already-lowered modules use the `len * 1000 + ord(first)` fold. Bool constants on already-lowered modules fold through `if` to 1 or 0. `urllib.parse.scheme_chars` stays fenced, and so do `ssl` contexts, sockets, and logging handlers. packaging's first fence is still `str | None` on `ELFFile.interpreter`, and it still does not count. Leave unions, `.values()`, `.items()`, `Optional`, keyword-only parameters, `abc`, `Generic`, and unannotated parameters fenced. Do not start `http.client`, user decorators, or upstream `requests`. The desugar-pass split of `lower.py` is still open.

Later iterations follow the fail-fast rule in `.agents/docs/loop.md`. Runs that left all five numerators unchanged are recorded in `benchmarks/compat/failed.jsonl` and are not repeated.

Surface is 1206/2478 after the int, str, and bool constant batches. The constant well on already-lowered modules is empty.

## Native and Rust extensions

A wheel's `.so` is almost always a Python extension module. Its entry point is `PyInit_*` and its functions take `PyObject *`. Linking that file into the small runtime does not give you `encrypt` or `ndarray`. Embedded CPython can import it, which is the island, and the speedup of that path stays near 1× once the `.so` is the work. A separate C ABI (`extern "C"`, a Rust `cdylib` with the same symbols) can be `dlopen`ed from the small runtime with no libpython. The measurement is [`benchmarks/native/`](../../../benchmarks/native/README.md).
