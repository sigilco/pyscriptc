---
title: Divergences from CPython
description: The parity contract and every numbered difference from CPython 3.14.
---

pyscriptc targets CPython 3.14.x. Parsing, probes and the compatibility oracle follow 3.14. Compiled programs match CPython 3.14 on stdout for everything that lowers, except the numbered divergences below. The empty divergence space is load-bearing: anything not listed here is claimed identical, and a difference you find that is not listed is a bug.

## Parity contract

- stdout: byte-exact for every lowered call. The corpus scorer today compares whitespace-stripped stdout; tightening that to unstripped bytes is planned work.
- stderr: for a `raises` probe, only the exception name must appear. Full traceback text is not matched.
- exit code: an uncaught exception prints its name to stderr and exits 1, as CPython does.
- Anything that does not lower is a named `PSxxxx` fence, not a divergence. See the generated [supported](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/support/supported.md) table and [refused-features](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/spec/refused-features.md).

## Numbered divergences

1. `int` is `i64`. Overflow aborts the process instead of growing a big int. Source: [refused-features](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/spec/refused-features.md) Tier C.
2. `//` by zero aborts the process instead of raising `ZeroDivisionError`. Source: same as item 1.
3. Strings are a Latin-1 byte model. A string literal outside Latin-1 is a fence, and `unicodedata` covers only Latin-1 code points. A normalization that would leave Latin-1 raises `ValueError`. Source: the `unicodedata` row of the generated [supported](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/support/supported.md) table.
4. `re` is the runtime's byte-oriented backtracking subset, not CPython's `re`. `L`, `T`, `DEBUG` and unknown flag bits raise `ValueError`, `A` and `U` are no-ops, and a pattern that can loop without consuming stops with `RuntimeError` once its fuel is spent. Five or more groups are refused. Source: header of `src/pyscriptc/runtime/ps_re.c`, `re` row of the generated [supported](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/support/supported.md) table.
5. `json` has no non-ASCII text. Source: `json` row of the generated [supported](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/support/supported.md) table.
6. Set and `frozenset` iteration is insertion order, not CPython's hash order. Length and membership match. Source: [refused-features](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/spec/refused-features.md) Tier C.
7. After `for i in range(0)`, a new loop target reads as `0` instead of raising `UnboundLocalError`. Source: [refused-features](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/spec/refused-features.md) Tier C.
8. A subclass `__init__` that never assigns an inherited field leaves it at the zero value of its type instead of raising `AttributeError`. Source: [refused-features](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/spec/refused-features.md) Tier C.
9. `raise AppError("no")` for a user exception class stores a code and an optional `str` and does not call `__init__`. Source: same paragraph as item 8.
10. `@classmethod` and `@staticmethod` of the form `Class.method(...)` do not pass the class object. Source: same paragraph as item 8.
11. Some library failures surface as a different exception type: `importlib.resources.files` on a zip or missing package raises `ValueError` rather than `ModuleNotFoundError`, `shutil.copyfile` of the same path raises `RuntimeError` rather than `SameFileError`, other `shutil` and `os` failures are `RuntimeError`, and type errors on `unicodedata` calls surface as `ValueError`. Source: the `unicodedata` and `importlib.resources` rows of the generated [supported](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/support/supported.md) table.
12. `assert` is always evaluated; a compiled binary has no `-O`. Source: [refused-features](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/spec/refused-features.md) Tier C.
13. `x is None` lowers as `==` against `None`. Identical for `None` because it is a singleton; every other `is` on a scalar is refused. Source: [refused-features](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/spec/refused-features.md) Tier C.
14. `ABC`, `ABCMeta`, `Protocol`, `@abstractmethod` and `@overload` lower as plain classes and methods with no CPython runtime semantics. Source: [refused-features](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/spec/refused-features.md) Tier C.
15. Island calls (`subprocess.check_output`, `socket.gethostname`, `threading`, `logging`) run in an embedded CPython, so those follow the interpreter the binary links, not the pin.
16. `dotenv` lowers a closed subset of python-dotenv's parsing rules, and it differs from the library in three places. The subset: a UTF-8 BOM is stripped, blank lines and whole-line comments are skipped, an `export ` prefix is allowed, keys are bare (`KEY` alone binds `None`), an unquoted value runs to the end of the line with the ` #` comment cut and the rest right-stripped, a double-quoted value decodes `\" \\' \\ \a \b \f \n \r \t \v` and a single-quoted one only `\\` and `\'`, and a later binding overwrites an earlier one. No interpolation (`$NAME` stays literal), no multi-line values, no quoted keys, and the `stream`, `verbose`, `interpolate`, `override` and `encoding` arguments are fenced. The three differences: a malformed line raises `ValueError` where python-dotenv skips it with a warning, a missing file parses as the empty document where python-dotenv searches with `find_dotenv()`, and `load_dotenv` does not overwrite a variable that is already in the environment (its `override=False` default) while still returning `True` for a document with bindings. Source: header of `src/pyscriptc/runtime/ps_dotenv.c`, `dotenv` row of the generated [supported](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/support/supported.md) table.
17. `yaml.safe_load` covers a closed YAML subset, not all of PyYAML: timestamps and sexagesimal numbers (`1:30`) raise `ValueError` where PyYAML resolves them to `date` and `int` objects, and errors surface as `ValueError` rather than `yaml.YAMLError`. Source: header of `src/pyscriptc/runtime/ps_yaml.c`, `yaml` row of the generated [supported](https://github.com/sigilco/pyscriptc/blob/master/.agents/docs/support/supported.md) table.
